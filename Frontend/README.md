TruthLens Project
Project Information
This is an AI-powered misinformation literacy platform. The project is designed to empower digital citizens with fact-checking tools, gamified critical thinking exercises, and collaborative projects.

How to Edit This Code
There are several ways to edit your application.

Use a Web-based IDE

You can use a web-based integrated development environment to edit the project directly. Changes made in the web IDE will be committed automatically to your repository.

Use Your Preferred Local IDE

If you want to work locally, you can clone this repository and push your changes. Pushed changes will be reflected in your online project.

The only requirement is having Node.js and npm installed.

Follow these steps:

# Step 1: Clone the repository using the project's Git URL.
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory.
cd <YOUR_PROJECT_NAME>

# Step 3: Install the necessary dependencies.
npm i

# Step 4: Start the development server with auto-reloading and an instant preview.
npm run dev

Edit a file directly in GitHub

Navigate to the desired file(s).

Click the "Edit" button (pencil icon) at the top right of the file view.

Make your changes and commit them.

Use GitHub Codespaces

Navigate to the main page of your repository.

Click on the "Code" button (green button) near the top right.

Select the "Codespaces" tab.

Click on "New codespace" to launch a new Codespace environment.

Edit files directly within the Codespace and commit and push your changes once you're done.
